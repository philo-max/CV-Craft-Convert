# 直接编辑简历画布设计

## 目标

将右侧 A4 预览升级为主编辑画布：用户可在纸张上直接修改可见文字、增加或删除项目条目，并用轻量工具条调整局部格式；所有更改继续写入现有结构化简历数据。

## 边界

- 不将整张纸设为一个无结构的 `contentEditable` 区域。
- 不引入完整 Word 或通用富文本编辑器。
- 模板、照片、模块排序、导入导出仍由文档工具区管理。
- 直接编辑必须与自动保存、修改历史、HTML/PDF/PNG 导出兼容。

## 交互

单击文本字段进入编辑态，字段边缘显示低干扰高亮。失焦或按 `Ctrl+Enter` 提交，`Esc` 放弃本次输入。多行项目描述使用可直接输入的文本区域样式，但在视觉上保持简历正文。

选中或聚焦字段后出现浮动工具条：字体、字号、加粗、文字颜色、对齐和段距。工具条仅作用于字段级格式，默认继承当前模板。未选中任何字段时工具条隐藏。

项目经历块提供悬浮操作：新增项目、删除项目、增加/删除工作项与成果项。删除须二次确认；新增插入默认空字段，不生成虚构内容。

## 数据模型

文字内容仍写入 `resumeData` 的既有路径，例如 `personalInfo.name`、`education.school`、`projects[i].name` 与 `projects[i].work[j]`。

局部格式写入独立的 `fieldStyles` 映射，键为稳定字段路径，值仅包含用户实际修改过的属性：`fontFamily`、`fontSize`、`fontWeight`、`color`、`textAlign`、`lineHeight`、`marginBottom`。未设置属性时由模板和全局排版配置决定。

预览、HTML 导出与画布共用字段路径和样式解析函数，确保编辑结果在所有导出格式中一致。

## 架构

`ResumePreview` 接收字段编辑回调和样式编辑回调。新增受控的 `EditableText` 与 `EditableBlock` 小组件：它们负责编辑态、快捷键、字段高亮和回调，不拥有简历数据。

`App` 继续拥有 `resumeData`、`layoutConfig`、`fieldStyles` 和历史保存逻辑。新增字段路径更新函数采用不可变更新，避免组件直接修改对象。

第一版采用字段级 `contentEditable`，只在用户进入编辑态时启用；提交时读取 `innerText` 并转换为对应字段值。Markdown 粗体与链接字段在第一版编辑时以纯文本处理，避免 DOM 富文本与现有 Markdown 渲染互相污染。

## 错误处理与可访问性

空字段显示占位提示但不会写入数据。未知字段路径不更新状态并记录控制台错误。删除项目必须经原生确认。键盘可通过 `Tab` 聚焦、`Enter` 编辑、`Esc` 取消与 `Ctrl+Enter` 提交。

## 验证

- 修改姓名、学校、项目标题、项目描述后，左侧数据、历史记录和导出一致。
- 新增/删除项目与工作项后，预览不出现 React key 或排序错误。
- 模板切换后，未局部覆盖的字段跟随模板；已覆盖字段保持用户格式。
- 验证鼠标、键盘和失焦提交路径，并运行 lint、生产构建和 Windows 打包。
