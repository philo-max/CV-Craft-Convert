# 简历编辑器排版与本地 AI 设计

## 目标

将 CV Craft 提升为克制的 Windows 文档编辑体验：模板可一键成型、预览与导出排版一致、内容可控地适配 A4，并提供真实可用的 LM Studio 本地 AI 润色。

## 非目标

- 不复刻完整 WPS/Office 功能区或文字处理器。
- 不自动编造经历、量化指标或技能。
- 不为了强制单页而无限缩小字体或边距。
- 不保存云端 API Key；本地 AI 配置仅保存在用户设备。

## 体验与信息架构

编辑页维持双栏：左侧为内容编辑与折叠的版式面板，右侧为 A4 预览。顶部保留少量文档级操作：保存状态、模板、导出和 AI 连接状态。

版式面板分为两层：

1. 模板：商务标准、经典文档、极简留白。选择模板一次写入字体、字号层级、单双栏、留白、标题样式、照片规则与密度。
2. 版式微调：面向需要精确控制的用户，提供字体、字号、页边距、行高、段距、分栏比例与分页辅助线。

## 字体与字号层级

默认字体为微软雅黑；可选等线、宋体、思源黑体和 Inter。每种选择必须对应完整的 Windows 优先字体栈，并同时用于预览、HTML 和 PDF/PNG 导出。

字号不再散落在组件内。排版配置持有以下层级（单位 pt）：

| 层级 | 标准值 | 最小值 |
| --- | ---: | ---: |
| 姓名 | 22 | 20 |
| 一级标题 | 12.5 | 12 |
| 项目/院校名称 | 11 | 10.5 |
| 正文 | 10.5 | 9.5 |
| 辅助信息 | 9 | 8.5 |

组件以 CSS 变量读取这些值，避免模板切换后只改变部分文本。

## A4 自适应策略

默认模式为“标准”：维持可读字号，必要时自然分页。用户可选择“紧凑”或“一页优先”。

一页优先仅在内容超过一页时按以下顺序收紧，并在每一步重新测量预览高度：

1. 项目与模块间距。
2. 正文行高。
3. 辅助信息字号。
4. 正文字号，最多下降 1pt。

若达到下限仍超出，显示明确的“建议精简内容”提示，不继续压缩。手动选择的字号与边距优先于自动调整，用户可一键恢复标准值。

## 模板模型

每个模板是一个完整不可变预设对象，包含：`fontFamily`、字号层级、布局类型、色板、边距、密度、标题样式、照片显示与默认分栏比例。模板选择会记录模板 ID；之后的手动微调不会丢失，但状态显示为“已自定义”。

## LM Studio AI

默认连接 OpenAI 兼容本地服务：`http://127.0.0.1:1234/v1`。启动时以及用户点击“检查连接”时请求模型列表，只有服务可达且存在已加载模型时才启用润色。

润色请求使用 `/chat/completions`，要求返回严格 JSON：三个改写建议与简短修改说明。每次建议显示原文、建议文本和“应用此建议”；不会自动覆盖原内容。

失败状态必须可解释：服务未启动、没有已加载模型、请求超时、返回格式不合法。默认移除 mock 模式和所有假性能/识别分数；未连接时只提示用户在 LM Studio 打开 Local Server。

## 验证

- 为每套模板校验预览、HTML、PNG、PDF 使用同一字体栈和字号变量。
- 用短、中、长三份简历验证标准、紧凑、一页优先的高度测量与下限行为。
- 为 LM Studio 连接成功、服务离线、无模型、非 JSON 返回和正常应用建议建立测试。
- 构建后手动验证 Windows 应用的模板切换、离线提示与一次真实本地润色。
