# 📄 CV Craft & Convert - 智能简历排版与自适应转换系统

> **CV Craft & Convert** 是一款专为极客与高端求职者打造的 **高保真、模块化、跨平台简历编辑与排版系统**。系统不仅包含极致细腻的前端视觉调优面板，更内置了 BGE-M3 语义匹配度引擎与 YOLO 视觉证件照审核等前沿小模型交互，帮助您的简历在内容和版面上同时实现“降维打击”！

---

## 🌟 核心特色功能

### 1. 🧠 BGE-M3 岗位匹配度分析与“一键调优”
* **语义相关性评分**：输入目标岗位的招聘需求 (JD)，系统将通过本地模拟的 BGE-M3 语义向量匹配算法，自动提取关键词并打出契合度评分；
* **一键一秒智能补全**：检测到模块或关键词缺失时，点击 **“✨ BGE一键调优”**，系统会自动重写项目描述，补齐目标 JD 核心技术栈（如 YOLO, RAG, Python 等），让匹配评分瞬间跃升至 100%。

### 2. 🎨 视觉版面设计调优（降维打击）
* **微米级排版设计器**：支持实时滑块调节 **页面边距** (10-30mm)、**模块间距** (6-30px)、**项目间距** (4-24px) 和 **正文行高** (1.3-1.9)；
* **CSS 主题主色配置**：支持 HTML 拾色器自定义主题主色、分割线颜色、纸张底色和文字主色；
* **标题装饰与字体预设**：内置 `▍ 左侧粗条`、`⎯ 下划分割线`、`🔲 边框包裹` 等高端简历装饰预设，并支持雅黑/Outfit/Inter 字体实时平滑切换；
* **✨ 智能版面一键缩至单页**：对于内容微超出一页的简历，一键自动收缩间距至黄金比例，让简历原生融入单页 A4 纸内。

### 3. 🖼️ Canvas 高清导出与 A4 切片生成器
* **🖼️ 导出高清长图 (PNG)**：采用离线克隆节点以 3x 像素精度（Scale: 3）在后台完成无损渲染，彻底避开屏幕滚动截断与侧栏挤压 bugs，输出超清矢量级大图；
* **📑 导出分页图片 (PNG)**：按照 A4 纵横比例（210:297）自动将超长简历切片为多张独立的 A4 图片并依次下载。

### 4. 🖨️ PDF 高保真双轨导出
* **🖨️ 导出 PDF (单页自适应)**：将简历整体比例自适应缩放至正好 1 页 A4 PDF，不留空白多余页，不切断任何文字；
* **📑 导出 PDF (多页分页版)**：对于多页内容的简历，精准纵向切片输出，适合学术型及资深开发者的多页简历投递。

### 5. 🤖 YOLOv8 证件照规范评估与激光扫描
* 上传头像照时，系统内置了 YOLOv8 人脸框检测模拟动画，提供绿框人脸锁定与人脸位置评分（YOLOv8 Face: 98%），并带有科技感十足的激光扫描线和合规审核反馈动效。

### 6. 🎵 Web Audio 实时合成写代码雨声 BGM
* 采用完全离线的 HTML5 Web Audio API 动态合成雨声白噪音（包含雨滴声、远景雷声与底噪过滤），零依赖、零体积、不占用任何网络宽带，带给您最沉浸的写代码体验。

## 📱 移动端与桌面自适应优化

* **响应式双面板**：在屏幕宽度小于 768px（如手机 App 或平板）时，布局自动由双栏并排折叠为 **单栏全屏切换模式**；
* **编辑/预览双态标签**：底部常驻磨砂背景导航栏，支持在“📝 编辑简历”与“👁️ 预览简历”两个全屏标签页间丝滑切换，保证小屏幕下的操作舒适度。

---

## 🛠️ 技术栈与架构

* **前端核心**：React 19 + Vite 8
* **样式处理**：Vanilla CSS 3 + Glassmorphic Backdrop
* **图片渲染**：`html2canvas` (离线节点渲染技术)
* **PDF 生成**：`jsPDF` (A4 页面切片算法)
* **桌面端壳**：Electron 31 & Electron Builder (便携式单文件打包)
* **移动端壳**：Capacitor 6 (原生 Android Gradle 编译)

```bash

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 编译静态资源
```

## 💻 跨平台客户端打包说明

### 1. 编译 Windows EXE 桌面客户端
我们在 `resume-app` 内集成了 **Electron** 环境。
```bash
# 在 resume-app 目录下执行
npm run build        # 编译最新 web 静态资源
npm run dist:win     # 使用 electron-builder 编译 Windows 便携版 EXE 文件
```
编译完成后，可在 `resume-app/dist/` 文件夹下找到免安装的 `${姓名}_简历_桌面版.exe`。

### 2. 编译 Android APK 安装包
我们在项目根目录集成了 **Capacitor** 移动端打包框架。
```bash
# 在 resume-app 目录下同步 Web 资源
npx cap sync

# 执行 Gradle 编译（需要本地已配置 Android SDK 和 Java 26）
cd android
./gradlew assembleDebug
```
编译完成后，可在 `resume-app/android/app/build/outputs/apk/debug/` 下找到安装包 `app-debug.apk`。
